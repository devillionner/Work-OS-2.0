## Робочий процес

- Після кожної завершеної задачі запускати `npm run verify`.
- Якщо verify проходить — зробити коміт із коротким описом українською та виконати `git push origin main`.
- Push у `main` автоматично оновлює сайт через Cloudflare, тому ніколи не пушити, якщо verify не пройшов.
- Не комітити `package.json` і `package-lock.json` без мого прямого прохання.
- Ніколи не виконувати `wrangler deploy`, міграції чи команди D1 з `--remote`.
