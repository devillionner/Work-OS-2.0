# Work OS 3.0

Особиста робоча панель для керування чатами, лідами й публікаціями з аналітикою — все в одному місці.
Приватний хмарний вебзастосунок (PWA) для ПК і смартфона. Один власник, один оператор.

## Робочий процес
- Завжди відповідай українською. Коміти — коротко, українською.
- Працюємо прямо в `main`. Push у `main` автоматично оновлює staging (Cloudflare Workers Builds), тому перед кожним push обов'язково:
  `npm run lint && npm run typecheck && npm run build`. Падіння будь-якого кроку означає не пушити.
- Нових тестів не писати, тестові набори не запускати. Тести, що перевіряли розмітку чи CSS старого UI, видаляються, а не лагодяться.
- Візуальна перевірка замість тестів: браузерне прев'ю на 390×844 і 1440×900, у темах «Ніч» і «День».
- Після кожного завершеного етапу онови `lib/app-meta.ts`: `APP_VERSION`, `APP_RELEASE_DATE`, `APP_CHANGES` (3–5 простих пунктів про реальну користь для оператора). Синхронізуй `"version"` у `package.json`.
- Залежності: дозволені тільки ті, що перелічені в розділі «Стек». Будь-яка інша нова залежність потребує мого прямого дозволу.

## Інфраструктурні запобіжники (не обговорюються)
- Ніколи не виконувати `wrangler deploy`, міграції чи будь-які команди D1 з `--remote`. Production (`work-os-production`) недоторканний.
- Єдина дозволена віддалена команда: `node scripts/d1-insights.mjs` (лише читання статистики staging).
- Бюджет D1: звичайний робочий день до 100 000 прочитаних рядків, у простої 0.
- Жодного опитування D1 за таймером. Зміни надходять live-каналом (Durable Object `workers/owner-channel.js` → `/api/live`, клієнт `lib/live-channel.ts`). Таймер дозволений тільки як фолбек, поки канал недоступний.
- Бекенд заморожений: `lib/`, `db/`, `workers/`, `app/api/`, `migrations/`, `scripts/`. UI використовує наявні API і дані. Новий ендпоінт чи SQL — тільки якщо без нього функція неможлива, з індексом і без сканування всіх записів власника.
- Фронтенд-зміни не потребують перезапуску runner на ПК оператора. Якщо зміна все ж його потребує, скажи про це явно.

## Стек
vinext (App Router, сумісний з Next, на Vite + Cloudflare Workers) · React 19 · Tailwind CSS v4 (CSS-first, `@theme` у `app/globals.css`, без `tailwind.config`) · @base-ui/react (лише як безстильні доступні примітиви) · GSAP + @gsap/react (useGSAP, Flip, Draggable) · lucide-react (stroke 1.5) · recharts (тільки в чанку аналітики) · cmdk (палітра команд) · @fontsource-variable/geist + @fontsource-variable/geist-mono (з кирилицею; якщо кирилиці немає — Onest Variable).
Заборонено: framer-motion, стильові пресети shadcn, CSS-in-JS, глобальні стейт-бібліотеки, react-query, іконкові шрифти.

## Дизайн-система «Frosted Field»
Суть: кінематографічне матове скло поверх атмосферного поля, монохромна типографіка, чорна «рейка» навігації, сигнальні кольори тільки для стану. Тиша замість декору.
- Теми: «Ніч» (основна, за неї проєктуємо першою), «День», «Система» (за замовчуванням). Атрибут `data-theme` на `<html>` ставить інлайн-скрипт до першого рендеру, без мигання.
- Єдине джерело токенів — `:root` / `[data-theme]` у `app/globals.css`. Захардкоджені кольори, радіуси й тіні в компонентах заборонені, тільки токени.
- Радіуси: рамка застосунку 3rem · панель 2rem · картка 1.5rem · внутрішній блок 1rem · контроли й кнопки — pill. Правило концентричності: внутрішній радіус = зовнішній − відступ.
- Шрифт: Geist. Вага ≤ 600, ієрархія будується розміром і прозорістю, а не жирністю. Усі числа — `tabular-nums`. Регістр — як у реченні, без КАПСУ кирилицею.
- Текстура: один глобальний шар SVG-шуму (feTurbulence) на `body::after`, `pointer-events:none`. Крапкова сітка — тільки на тлі теми «День».
- Скло: максимум 2 шари `backdrop-filter` в одному в'юпорті. На елементах списку, що прокручується, blur не ставимо. Фолбек — суцільна поверхня для `prefers-reduced-transparency` і браузерів без `backdrop-filter`.
- Рух: GSAP, анімуємо тільки transform, opacity і filter. 180–420 мс, ease `expo.out` / `power3.out`. Усе загорнуто в `gsap.matchMedia()` з гілкою для `prefers-reduced-motion`.

## Анти-патерни (миттєвий відкат)
Фіолетово-сині градієнти · градієнтний текст · емодзі в UI · «✨» та AI-блискітки · неонові обведення · font-bold/extrabold · дефолтний вигляд shadcn (slate-200 рамка + rounded-lg + shadow-sm) · `ring-black/[0.02]` · бейдж на кожному елементі · іконка біля кожного підпису · гігантські ілюстрації в порожніх станах · Title Case · знаки оклику в текстах · lorem ipsum · мок-дані · «Скоро буде» · TODO-коментарі · заглушки з `disabled` · `console.log`.

## Архітектура фронтенду
- `app/globals.css` — токени, база, шум, утиліти скла (≤ 350 рядків).
- `components/ui/` — примітиви системи.
- `components/shell/` — каркас: AppFrame, Rail, Topbar, Dock, PulseRail, Inspector, Sheet, CommandPalette, Atmosphere, LiveOrb, ThemeProvider.
- `components/motion/` — одноразова реєстрація GSAP-плагінів (тільки на клієнті), хуки useMagnetic, useSpotlight, useReveal, useCountUp, спільні таймлайни.
- `components/views/<розділ>/` — today, platforms, leads, analytics, reports, library, settings. Кожен розділ підвантажується ліниво.
- Деталі сутностей відкриваються в Inspector (праворуч, на ПК) або в Sheet (знизу, на телефоні). Модальні діалоги — тільки для підтверджень.

## Карта екранів
Функція прототипу 2 → місце в 3.0. Нічого не губиться; рідкісне й технічне живе в «Налаштування → Сервіс».
Позначки: [шелл] каркас · [inspector] праворуч на ПК / Sheet знизу на телефоні · [підтвердження] модальний ConfirmDialog.

**Каркас**
- Навігація (Сьогодні, Платформи, Ліди, Аналітика, Звіти, Бібліотека, Налаштування) → Rail на ПК, Dock + «Ще» на телефоні. Лічильник лідів → тільки в підписі розгорнутої Rail.
- Заголовок розділу, дата → Topbar. Привітання за часом доби → «Сьогодні».
- Глобальні таймери (платформа, 5/10/15 хв, звук, закриття) → Topbar: кнопка-pill з найближчим таймером → скляне меню (Sheet на телефоні).
- Обліковий запис, вихід → меню аватара в Topbar + «Налаштування → Профіль».
- Що змінилося (`AppReleaseDialog`), версія → «Налаштування → Сервіс → Версія» + палітра команд.
- Тест екрана оновлення, автооновлення PWA (банер, екран прогресу, відновлення розділу й скролу) → екран оновлення перестилізовано (`pwa-registration`); тест — «Налаштування → Сервіс».
- Збереження активного розділу (`view-persistence`) → стан розділу в `components/shell` (localStorage), без DOM-хаків.
- Вхід через Google, екран завантаження, ліміт D1 → один екран входу в стилі «Frosted Field».
- Нове: палітра команд (⌘K), перемикач теми (Ніч / День / Система), LiveOrb, PulseRail (телефон).

**Сьогодні**
- Робочий день (почати, пауза, продовжити, завершити з підтвердженням незавершених, повернути, скинути з підтвердженням, план дня) → велика pill у рядку 1.
- Фокус дня (напрямки, кількість чатів і лідів, «Почати постинг», «Налаштувати ціль») → інвертована картка «Фокус».
- Налаштування цілей і напрямків (`TodaySettingsDialog`: денна/місячна ціль, цільова конверсія, напрямки) → [inspector], відкривається з «Фокус» і з «Налаштування → Цілі дня».
- Історія цілей (`GoalHistoryDialog`) → [inspector] з «Налаштування → Цілі дня».
- Ціль записів (виконано з цілі, місячна ціль, стан звіту) → KPI-плитка «Записи» + кільце.
- Результат за платформами (публікації, нові чати, відгуки, записи) → KPI-стрічка + розбивка по платформах.
- Прострочені ліди й нагадування (копіювати, надіслано, відкрити ліда; секції Сьогодні/Завтра/Повторні контакти) → черга в рядку 3.
- Розклад Telegram на сьогодні → шкала рядка 4; повне керування (генерація, налаштування, слоти, архів, відв’язати) → «Платформи → Telegram → Розклад».

**Платформи** (`platform-workspace`, `platform-overview`, діалоги чатів)
- Вибір платформи за увімкненими; пам’ять останньої платформи й черги → список платформ ліворуч.
- Черги (Для приєднання, Очікування, Для публікації, Уточнити профіль, Архів, Відібрані для Telegram) з лічильниками, пошук, фільтр «Потребують правил», пагінація → ліва колонка.
- Дії рядка чату (приєднано, очікуємо, не вдалося, прийняли, опублікувати, +3 дні, повернути, профіль, відновити, видалити назавжди, «Я вийшов», копіювати, відкрити, історія, в архів) → рядок і робоча зона чату; скасування протягом 8 с → Toast.
- Причина архівації, перепризначення акаунта, повернення до приєднання, видалення назавжди → [підтвердження].
- Профіль і правила чату → [inspector], вкладка «Профіль». Історія чату → вкладка «Історія». Публікація (матеріал, мова, швидкий режим Viber) → вкладка «Публікація».
- Додати чати (bulk), CSV, перевірка назв, менеджер дублікатів → [inspector]/Sheet з кнопки «+ Створити» і з «Налаштування → Сервіс».
- Знайти нові чати (discovery WhatsApp/Viber) → покроковий потік у [inspector]/Sheet; панель executor → «Налаштування → Сервіс»; у робочій зоні лише «Runner на зв’язку / офлайн».
- Telegram: акаунти (вибір, керування, перерва, ліміт приєднань), прогрів акаунта, відібрані чати → заголовок Telegram, вкладка «Огляд», черга «Відібрані».
- Telegram розклад публікацій → вкладка «Розклад».
- WhatsApp: перевірка заявок (waiting check), автопост (фото, текст, черга, стоп, скинути черги) → черга «Очікування» і вкладка «Публікація» (картка-редактор поста).
- Темп публікацій, доступні сьогодні, приєднані сьогодні, опубліковані → вкладка «Огляд».

**Ліди** (`components/leads/*`)
- Список, пошук, фільтри → режим «Список»; дошка за статусами → режим «Дошка» (перетягування); учні → «Ліди | Учні».
- Новий/редагування ліда, копіювання Telegram/телефону/нотатки, історія ліда → [inspector] ліда.
- Розмова (повідомлення, вкладення, видалення, довантаження старих) → вкладка «Розмова». Нагадування → «Нагадування». Уроки (створити, історія, запит куратору, скасування) → «Заняття». Історія → «Історія». Скрипти RU/UA → «Скрипти». Етапи воронки, follow-up, перша відповідь → шапка Inspector.
- Відгуки та записи за день (`today-activity`) → смуга над дошкою.

**Аналітика** (`analytics-*`)
- Період (пресети, початок/кінець) → pill у Topbar; «Експорт» → контурна pill.
- KPI з дельтою, активність за днями, інсайти, воронка («Де втрачається результат»), предмети, платформи, ліди за чатами-джерелами, результат уроків, рейтинг чатів із фільтрами, що сталося з відгуками (когорти) → розділ аналітики; метрика (`analytics-metric-dialog`) → [inspector].

**Звіти** (`reports-workspace`, `report-*`)
- Календар звітів → стрічка днів; текст звіту (редагування, зберегти, здати, копіювати), версії й відновлення → звіт дня + [inspector] «Версії».
- Проміжні звіти (чекпоінти) → вертикальна шкала. Ручні корекції (чати, публікації, результати уроків), різниця факту й ручного → [inspector]. Статистика предметів, джерельні події, відкрити ліда, ретроспективний лід → звіт дня.

**Бібліотека** (`library-workspace`, `library-history-dialog`)
- Матеріали (створити, редагувати, RU/UA, копіювати, архівувати, відновити, Viber safe-mode, історія) → сітка карток-папок, редактор і історія в [inspector].

**Налаштування**
- Профіль, вихід → «Профіль». Цілі дня, історія цілей → «Цілі дня». Увімкнені платформи → «Платформи». Зарплата, бонуси, прогноз → «Оплати».
- Тема, атмосфера (власне фото в IndexedDB), щільність → «Вигляд».
- Сервіс: хмарна резервна копія і перевірка/відновлення, перевірка назв, дублікати, CSV, executor/runner discovery, версія і що нового, тест екрана оновлення.
- `legacy-import-dialog` (Prototype Checker) у прототипі 2 не підключений ні до одного екрана — мертвий код, у 3.0 не переноситься й видаляється при прибиранні; повернення лише за прямим рішенням власника. `/audit-access` — серверний маршрут, а не екран.
- Небезпечні дії → окрема секція внизу з підтвердженням.
