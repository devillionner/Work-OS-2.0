# Work OS 2.0

Новий browser-first Work OS для постингу, обліку чатів і лідів, звітів, цілей та перевірюваної аналітики.

## Статус

Проєкт створено окремо від робочого Prototype Checker. Поточний застосунок і його дані не змінюються, доки нова версія не пройде міграційні та наскрізні перевірки.

## Як працюватиме

- застосунок відкривається за звичайною HTTPS-адресою в будь-якому сучасному браузері;
- frontend розміщується на хмарному hosting/CDN і працює незалежно від домашнього ноутбука;
- Google OAuth виконує вхід, а сервер допускає лише дозволений Google-акаунт;
- центральна PostgreSQL-база зберігає однакові дані для Windows, Linux та iPhone;
- локальний браузерний кеш прискорює роботу і тримає контрольовану чергу змін при коротких збоях мережі;
- перевірені резервні копії та версійні міграції захищають накопичену базу.

До завершення перевіреної міграції Work OS 2.0 працює лише з копією даних. Стара база не очищується і не перезаписується автоматично.
