# Work OS 2.0

Приватний вебзастосунок для щоденної роботи з чатами, публікаціями, лідами, звітами, цілями та аналітикою. Проєкт перебудовується окремо від старої версії, щоб не ризикувати наявною базою.

## Поточний стан

- адаптивна оболонка для Windows, Linux та телефона;
- власний Cloudflare Worker і окрема база D1;
- нова дизайн-система й уніфікована навігація;
- підготовлене хмарне сховище D1 у європейському регіоні;
- Google-вхід для одного дозволеного акаунта;
- безпечний імпорт резервної копії через staging-перевірку;
- налаштування фокусу, цілей і видимих робочих платформ.

Поточна хмарна адреса: <https://work-os-2.devillionner.workers.dev>

## Локальний запуск

Потрібен Node.js 22.13 або новіший.

```bash
npm install
npm run dev
```

Відкрийте адресу, яку покаже команда. Локальний режим використовує окрему
локальну копію D1 і не змінює хмарні дані.

## Перевірка перед змінами

```bash
npm run build
npm run lint
```

## Публікація у власний Cloudflare

Після одноразового `npx wrangler login`:

```bash
npm run deploy
```

Для production використовуй окремий явний environment:

```bash
npm run deploy -- --env production
```

Звичайний `npm run deploy` працює зі staging-конфігурацією. Production deploy
не виконується автоматично від push у `main`, щоб випадково не змінити робочі
дані.

Сайт працює незалежно від підписки ChatGPT. Робочі дані зберігатимуться в
Cloudflare D1, а код — у цьому GitHub-репозиторії.

## Архітектурні принципи

1. Хмара є основним джерелом даних; браузер не є базою даних.
2. Усі робочі результати зберігаються як події: публікація, відгук, запис, урок, звіт.
3. Екрани платформ мають спільну структуру, а платформні правила є конфігурацією.
4. Міграція зі старої версії відбувається тільки через резервну копію, перевірку та попередній перегляд.
5. Зовнішні корпоративні системи не інтегруються і не змінюються.

Детальніше: [архітектура](docs/ARCHITECTURE.md) та [безпечна міграція](docs/MIGRATION.md).
